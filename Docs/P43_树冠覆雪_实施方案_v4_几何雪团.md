> **依据**：`P43_树冠覆雪_调研_v2_真实形态与技术路线.md`（真实形态 9 条 + 四路线裁决）

## 零、结论

**是，方法已找到，且能确定 v3 为什么必败。**

不是参数不够，是**两处结构性错误**：

| # | 错误 | 证据 | 后果 |
|---|---|---|---|
| 1 | 雪斑是**平面片**，与 alpha 叶卡同层 | 叶卡单张 2~5m，雪斑 0.45~0.95m 贴在卡面上 | 侧视被外层叶卡遮死，只剩冠顶零星白点 |
| 2 | 材质是**半透明 + 边缘渐隐**，且悬浮 0.34m | `SnowGround.shader` 第 96/106 行：`Queue=Transparent`、`Blend SrcAlpha OneMinusSrcAlpha`；第 477 行 alpha = `smoothstep(...) * cov * edge` | 每片都变成"软边白气球"，飘在冠外 → 图里那些雾球 |

**所以 v4 换两条根：几何体（有厚度）+ 不透明材质（无渐隐、贴面）。**

## 一、图中三个病灶（逐个对到参数）

| 病灶 | 现象 | 根因 | 处置 |
|---|---|---|---|
| ① 冠外白色雾团 | 树冠外围飘着几团半透明白球，边缘发虚 | 悬浮 `foliageHover=0.34` + 透明 Blend + 径向渐隐 | 贴面 0.05~0.12m；换不透明材质 |
| ② 树冠本体仍墨绿 | 走近看叶子上一片白都没有 | 平面片全部被叶卡自身遮挡（同层） | 改几何团块，从冠面"鼓出来" |
| ③ 远景整排树仍深绿 | 40m 外真实雪树应是灰白块面 | 覆盖率不足 + 片太小，远处衰减成噪点 | 雪团幂律尺寸 + 远距离 LOD 放大 |

## 二、方案结构（三层，按观感权重排）

| 层 | 占比 | 作用 | 实现 |
|---|---|---|---|
| **A 雪团** | ~70% | 主体。冠面上鼓出的一团团厚雪 | 不透明低模椭球，只放"外缘 + 朝上"位置 |
| **B 雪脊** | ~20% | 侧视轮廓的白边 | 沿叶卡最高边的细长椭球条 |
| **C 冠内补白** | ~10% | 缝隙里透出的白，防"只有壳没肉" | 现有雪斑保留，改不透明 + 贴面 0.05m |

**A 不成立就不用做 B/C。** 一次加一层，便于归因。

## 三、A：雪团生成算法

```
输入：每棵树的叶卡集合（复用现有 protoCards，已按"冠顶区段"过滤）
输出：合并进一个 mesh 的雪团几何

foreach tree:
    C   = 冠心（叶卡包围盒中心）
    R   = 冠半径（包围盒水平半径）
    Ytop= 冠顶

    // ① 采候选点：只取"外缘 + 朝上"的叶卡顶点
    foreach card in 冠顶区段叶卡:
        foreach v in card.verts:
            n      = normalize(冠心→v 的水平方向) × 0.5 + card.normal × 0.5
            upward = dot(n, Vector3.up)
            if upward < 0.25        continue      // 下表面不挂雪（真实第 2 条）
            radial = 水平距冠心(v) / R
            if radial < 0.55        continue      // 冠内被上层挡住（真实第 4 条）
            score  = upward * radial * Perlin(v*3.7 + treeSeed)
            candidates.add(v, n, score)

    sortDesc(candidates by score)
    N = 28 + round(冠幅/2)          // 28~45
    foreach 前 N 个候选:
        size = PowLawSample(min=0.35, med=0.60, max=1.60)   // 真实第 1 条：尺寸极不均
        pos  = v + n * 0.08                                  // 贴面，不是 0.34
        pos += up * (-size * 0.18)                           // 埋入叶片，只露上半
        blob = IcoBlob(tri=20, squashY=0.42, jitter=±15%, yaw=随机)
        mesh += Transform(blob, pos, size, treeMatrix)       // 含 rotation/widthScale/heightScale
```

### 幂律尺寸分布（关键：不许同尺寸）

| 档 | 占比 | 尺寸 | 用途 |
|---|---|---|---|
| 小 | 70% | 0.35~0.70m | 填充缝隙、打散 |
| 中 | 25% | 0.80~1.10m | 主体团 |
| 大 | 5% | 1.20~1.60m | 冠顶主团，远景靠它读成白 |

## 四、B：雪脊生成算法

```
foreach 外缘叶卡:
    e = 该卡 Y 最高的边（两端点取高者之间）
    沿 e 均布 3~5 段：
        条 = IcoBlob(squash=(0.16, 0.16, 0.25))  // 细长扁条
        长度 = 边长 * 0.25，宽 0.12~0.18
        位置 = e 中点 + up*0.03
```
只做外缘，段数按边长自适应。这条是"侧视白边"的唯一来源，缺了侧视永远像没雪。

## 五、材质（必须新做，不能复用 SnowGround）

现有 `SnowGround.shader` 是**半透明**材质（`Queue=Transparent` + `Blend SrcAlpha` + 边缘 `edge` 淡出），这是雾球的直接来源。v4 新增一个极简不透明雪材质：

| 项 | 规格 |
|---|---|
| 文件 | `Assets/_Project/Scripts/Weather/Resources/SnowClump.shader`（与既有 shader 同目录） |
| 队列 | `Queue=Geometry(2000)`、`RenderType=Opaque`、无 Blend |
| 基色 | **读同一份 `_SnowColor`**（与屋顶雪壳同口径，不许自己定色） |
| 受光 | 走场景光照（非 unlit），否则夜里会发亮 |
| 细节 | 世界坐标 3D 噪声扰动明度 ±6%，压掉"塑料球"感 |
| 雪量驱动 | 读 `_GlobalSnow`；0→1 时用 `scale` 从小到大长出来（不是 alpha 渐现） |
| 阴影 | `CastShadows = Off`（与屋顶雪壳同口径，防地面上出现一团团硬阴影） |

> **必须同步动作**：屏幕快照链按材质名过滤（`Monitor04*` / `TwinScreen_*`）。新增材质名要一并加进排除名单，否则雪团可能被当成"屏幕"捡走。这是 v1 雪壳事故的原型（幕布被盖）。

## 七、LOD（解决病灶 ③）

| 相机距离 | 策略 |
|---|---|
| < 15m | 全量 40 团，尺寸 ×1.0（近看有结构） |
| 15~30m | 团数 60%，尺寸 ×1.25 |
| > 30m | 团数 40%，尺寸 ×1.6（合并成白色块面，对齐真实第 8 条） |

切换按每棵树到相机距离算，只重建一次（不做逐帧），进场时算好。

## 八、验收（三机位 + 四指标）

固定机位：俯视 60° / 侧视 45° / 远景 40m，同一棵树、同一档雪量。

| 指标 | 门槛 | 不过怎么办 |
|---|---|---|
| **侧视可读** | 侧视 45° 能看出白团轮廓 + 团间暗缝 | **不过就是方案不成立**，转路线 D（换冬季树） |
| 覆盖率 | 树冠白色像素 55~70% | <55 加团数；>75 减尺寸 |
| 暗部保留 | 冠底/枝下暗像素 ≥25% | 减冠内补白 |
| 白雾球 | 画面中不得出现边缘发虚的半透明白团 | 查材质队列与 hover |

回归（沿用现有判据）：角色落地 / 室内判定 / 幕布链无混入 / `totalLights=404`。

## 九、实施顺序（一次一层，验一层）

1. 停 Play，**先给当前 v3 这版拍一张留证图**（`P43_v3_patch_0320_before.png`），它是"参数放大无效"的证据

4. `refresh_unity` → 核 dll 时间戳 > 最后 `.cs` → 进 Play
5. 拍三机位，只看一条：侧视有没有白团鼓出来
6. 过了再加 B（雪脊），再验侧视
7. 过了再加 C（冠内改不透明贴面），再验
8. 补判据（新增护栏：材质队列=Opaque、hover ≤0.12、团数>0）→ 判据全绿 → 回执 → 提交

## 十、回滚与风险

| 风险 | 应对 |
|---|---|
| 团块变棉花糖 | 幂律 + 上限 1.6m + 覆盖率闸门 75% |
| 团块埋进叶里看不见 | 只露上半（pos -= up*size*0.18），必要时提到 -0.10 |
| 不透明团与半透叶卡排序打架 | 团块在几何队列，先画；叶卡后画，天然覆盖正确 |
| 夜里团块发灰 | 用雪壳 `_SnowColor`，别自己调；夜里低照度下允许偏暗（真实第 6 条） |
| 又被全局遍历捡走 | 材质名进排除名单 + 不带 Collider + 不进屏幕快照链 |
| **改完没验证**（本次事故） | 三张固定机位截图必须落盘，禁止只报读数 |

## 十一、如果 A 层侧视还是不成立

不是继续调参，直接转 **路线 D：换冬季低模树**（锥形/球冠 + 雪材质），35 棵地形树原型替换。理由：本素材的叶卡是写实大卡，天生不适合"几何挂雪"；换形态比改几何便宜。

判定门槛：A 层做两轮（参数 + 结构改），侧视仍读不出"白团鼓出来"，即转 D。
