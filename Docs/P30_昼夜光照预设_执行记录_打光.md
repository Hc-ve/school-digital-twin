## 一、结论先行

**在不重烘、不换材质、不换天空盒的前提下，让占全场 95% 的烘焙表面整体变暗，唯一手段是后处理曝光。而本工程的 PPS v2 后处理实测完全没有作用。**

用极端探针验证：把 `ColorGrading.postExposure` 设到 **−4 EV**，渲染出来的画面**亮度没有任何变化**（`P30_light_probe_exp.png`）。−4 EV 相当于暗 16 倍，肉眼必然全黑；实际图与正常白天一致。

**⇒ 昼夜三档目前只有雾和环境光的差别，读不出昼夜。任务包给的四个手段里，前两个（平行光、环境光）对烘焙表面无效，第四个（曝光）不工作，只剩雾。**

## 二、为什么前两个手段无效（已在前几轮字节级验证）

| 手段 | 现状 | 对烘焙表面是否生效 |
|---|---|---|
| Directional 颜色 + 强度 | `m_Lightmapping: 1` = **Baked** | **否**。烘焙光不参与实时渲染，运行时改它等于改一个没人读的变量 |
| 环境光（ambientMode / SkyColor / Intensity） | Skybox, 1.0 | **否**。Standard shader 走 `LIGHTMAP_ON` 分支时不叠加 SH 环境光。早前已用「改前改后 PNG 字节完全一致」证明 |
| 雾 | `m_Fog: 0` 关闭 | **是**（屏幕空间），但只能做远近层次，不能整体压暗 |
| 后处理曝光 | PPS profile 原本为空 | **本该是**，实测不工作 |

## 五、后处理为什么不生效（已排查的部分）

| 排查项 | 结果 |
|---|---|
| 相机上有 `PostProcessLayer`？ | **有**（PPL=有） |
| `m_Resources` 引用有效？ | **有效**（guid `d82512f9…` 对应包内 `PostProcessResources.asset`） |
| Profile 里有 ColorGrading？ | **有**（本轮补齐，读回 3 项） |
| 参数写进去了？ | **写进去了**（日志读回 exp=0 / −0.30 / −1.05 / 探针 −4） |
| `gradingMode` 是 HDR？ | **是**（已强制 `HighDefinitionRange` + `Neutral`） |
| `finalBlitToCameraTarget`？ | 原为 `false`，**已强制 `true`** 后图仍有变化但曝光无效果 |
| 结论 | 参数层全对，**渲染管线层没吃到** |

**10 秒就能判定**：主理人开编辑器进 Play，选中相机上的 `Post Process Volume`，把 `Color Grading → Post exposure` 拖动。画面跟着变 → PPS 正常，是我离屏渲染的问题；画面不动 → PPS 本身坏了，需要断点修 Layer/Volume 接线。
