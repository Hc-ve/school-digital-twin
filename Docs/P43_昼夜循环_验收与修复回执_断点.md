## 二、验收发现的 4 个缺陷与修复（全部已落地）

### P0 · 密度三档对主雨雪完全失效（修复 1）
- **实测根因（非猜测）**：`RainParticles`/`SnowParticles` 因 P13-D9 刻意**不挂父节点**（世界坐标定位，挂子级会被楼板吃掉发射盒），而 `ApplyParticleDensity` 用 `GetComponentsInChildren` 只够到子级 `RainSplash`。实测切「小」：雨丝 3200 粒/s、4699 粒纹丝不动，仅水花倍率变化。另微测试证实三份速率曲线均为 **Constant 模式**，`rateOverTimeMultiplier` 在该模式下读改不可靠且会被 Apply 重写覆盖——multiplier 方案整体废弃。
- **修法**：`WeatherVisuals` 新增 `SetDensityScale(k)`（复位 lastRain/lastSnow/lastSplashRain 三缓存为 -1 哨兵，强制下一次 Apply 全量重写）+ 三路写入乘 `_densityScale`（默认 1，行为与历史版本一致）；`TimeCycleDirector.ApplyParticleDensity` 改调它。
- **复验实测**：雨 Medium 3200 → Low **1120(=3200×0.35)** → High **6400(=3200×2.0)** → Medium 3200；雪 Low **182(=520×0.35)**；粒子数实时跟降（4714→1647→8995）；跨天气切换（雨→雪）倍率持续生效。

### P1 ·「随机」按钮语义矛盾（修复 2）
- **根因**：旧实现点「随机」= 摇一次骰子 + `SetAuto(false)` 永久退出自动轮换，之后无任何 UI 路径能回随机模式——与主理人"默认处在随机选项、循环中随机天气"诉求相反。
- **修法**：`CommitPendingWeather`：确认「随机」= `SetAuto(true)` 回权重链（`SetAuto(true)` 自带缩短首次轮换计时）；确认具体档才 `SetAuto(false)`。
- **复验实测**（走真实 UI 路径反射调用）：雨天+确认→auto=False ✓；随机+确认→auto=**True** ✓；晴天+确认→False ✓；随机+确认→True ✓。

### P2 · 初始高亮误导（修复 3）
- **根因**：play 后系统实际处于自动随机模式，但天气钮高亮「晴天」（当前档），误导"天气被钉死"。
- **修法**：`RefreshButtons` 增分支：无预览且 `WeatherDirector.Instance.auto` → 高亮「随机」（模式语义优先于当前档）。
- **复验**：auto=true 时钮[0]◉选中其余未选；截图 `P43_fix_verify_random_highlight.png`。

### P2 · 面板冻结基准不同源（修复 4）
- **根因**：`Pause()` 冻结用墙钟 `CurrentHour()`，而 `Resume()` 与表盘都读 `TwinClimate.HourOfDay`——三处两口钟，每次开合面板静默丢最多一帧的游戏时间（掉帧时放大到数游戏分钟，实测表盘 08:03 vs 冻结 08:06）。
- **修法**：`Pause()` 改取 `NormalizeHour(TwinClimate.HourOfDay)`。
- **复验**：面板开着时循环冻结值 = 数据侧时刻 = **0.00000000 差值**（修复前 ≈ 0.002~0.05h）。

## 六、追补（11-17 凌晨 · 主理人 play 反馈：撒播高度太低）

**反馈原话**：雨雪撒播高度只比教学楼高一点点，现实不是这样，要求调高。

**取证**：`EmitHeight = 16f`（WeatherVisuals.cs:25），发射点真实语义 = **室外地面 + 16m**（`UpdateGround` :3912 `emitPos.y = outdoorGroundY + EmitHeight`，:25 旧注释写"相机上方"是过时表述）。教学楼约 15~16m ⇒ 雪恰好从楼顶一线凭空出现，观感属实。

**修法（4 处）**：
1. `EmitHeight 16 → 60`（教学楼 3.75 倍）。寿命**不用改**：`UpdateRainLifetime`/`UpdateSnowLifetime` 是按实测落距解 `t=√(2h/g)` 的解析式（0.5s 节流重算），落距变大自动跟随——设计初衷就是防"落距变了寿命写死"。
2. 雨 `maxParticles 9000 → 24000`：60m 落程下雨寿命 1.6s→~3.0s，活跃 ≈ rate×t（Medium 9.8k / High 19.6k），旧 9000 会**静默截断发射**（缓冲满=新粒子不发射=雪变稀且无报错，P28-01 同型病）。
3. 雪 `maxParticles 6000 → 22000`：雪寿命 9.6s→~18.3s（仍在既有 Clamp[4,30] 内），Medium 9.5k / High 19k。
4. 雪天自检文案硬编码「EmitHeight 16」改为拼接常量（G5：文案不许与实现脱节）。

**实测**：撒播高度 60.0m（发射器 Y 59.50 − 地面 −0.50）✓；雪寿命 9.6→17.2s 自动跟随 ✓；活跃 8791 < 22000 无截断 ✓。取证 `Docs/QA/evidence/P43_snow_emitheight60.png`（数值看板）。
（注：两颗上限按 High 满载留 15~22% 余量；白天雪片对亮天对比度低属既有特性，夜间最明显——主理人原始截图即夜间效果。）
