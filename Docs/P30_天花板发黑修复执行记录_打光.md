## 二、试过的五种手段与实测结果

| # | 手段 | 结果 | 证据 |
|---|---|---|---|
| 1 | 改 `RenderSettings.ambientMode / ambientLight / ambientIntensity` | **无效**。改前改后 PNG **字节完全一致** | `before` 与 `amb0.6` 的 MD5 均为 `141943ab6a37c93c701019e9345d460b`（三块吊顶各自组内都相同） |
| 2 | 深蓝补偿值 `#2A3A50` / 0.6 | **视觉更差**：天花板被刷成一片深海蓝，与暖灰墙面强烈冲突 | `P30_fix_Class2-1_t1_2A3A50_x1.0.png` |
| 3 | `Floor2` 的 `m_ReceiveGI=0` + `m_LightProbeUsage=0`（保存后重开） | **无效**。重开读回确实是 0，天花板仍纯黑 | `P30_after_Class2-1.png` 与修复前一致 |
| 4 | `Floor2` 的 `m_StaticEditorFlags` 清零（保存后重开） | **无效** | 同上图 |
| 5 | **运行时 `lightmapIndex = -1`** | **✅ 有效**。天花板恢复为正常混凝土质感，灯管贴回天花板，墙面不变 | `P30_fix_Class2-1_bypass_only.png` |

### 为什么 1、3、4 都无效

- **1 无效**：内置管线 Standard shader 走 `LIGHTMAP_ON` 分支时直接采样光照贴图，**不再叠加 `unity_Ambient*` 的 SH 项**。环境光在烘焙时就烤进贴图了，运行时改它等于改一个没人读的变量。
- **3、4 无效**：`m_ReceiveGI` / `LightProbeUsage` / `StaticEditorFlags` 只影响**烘焙时**怎么生成 GI，不改变**运行时**已经存在的 lightmap 绑定。绑定来自 `LightingData.asset`，由 Unity 在场景加载时重新指派。
- **5 有效**：直接改运行时绑定值，绕过整个烘焙管线。

### 附加发现：`ambientIntensity` 在 batchmode 下不生效

档位 `#2A3A50 × 1.0` 与 `#2A3A50 × 1.8` 的 `RenderSettings.ambientProbe` 完全相同（`0.0232, 0.0423, 0.0802`），PNG 也字节一致。只有换颜色才改变 probe。这说明 batchmode 下 intensity 不进 SH 刷新——这本身也是"环境光路线不可控"的旁证。

## 三、唯一的可行路径（需跨边界）

`Renderer.lightmapIndex` 是运行时字段，不给它赋值就永远是 6。持久化只有三条路：

| 方案 | 具体做法 | 归属 | 工时 | 风险 |
|---|---|---|---|---|
| **A（推荐）** | 写一个极小的 MonoBehaviour，`Awake()` 里把 `Floor2` 的 `lightmapIndex` 置 `-1` | **C# 逻辑开发（断点）** —— 按我的边界，代码不归我写 | 10 分钟 | 极低，可回滚（删组件即可） |
| B | 我在场景里加一个这样的组件 | 需你破例授权"动场景结构 + 写代码" | 20 分钟 | 低 |
| C | 重烘 | 我 | 1.5–4 h 机时 | 高：不可逆、全场景观感会变、P29 UI 视觉对齐需复核 |

**给断点的实现规格（直接可粘贴）**：

```csharp
// 挂在场景里任意一个常驻 GameObject 上（如 [TwinRuntime]）
using UnityEngine;

public class P30FixCeilingLightmap : MonoBehaviour
{
    [SerializeField] Renderer target;   // Inspector 里拖 SchoolScene/Exterior/SchoolBuilding/Floor2

    void Awake()
    {
        if (target != null) target.lightmapIndex = -1;
    }
}
```

要点：
1. **不要用 `GameObject.Find` 按路径找** —— 场景 12 万行，路径不可靠。必须在 Inspector 里拖引用，序列化到场景里。
2. 只改 `lightmapIndex`，**不动材质、不动 RenderSettings**。
3. 回滚 = 禁用/删除这个组件。
