## 二、真根因：烘焙分辨率不足

### 定量

| 项 | 数值 |
|---|---|
| 光图 UV 岛 | **33 × 33 px**（1090 纹素） |
| ST scale | 0.0325（0.992 × 0.0325 × 1024 = 33px） |
| 暖气模型 | 0.95 × 0.83 × 0.09 m，668 顶点 / 612 三角 |
| 翅片数 | 约 12 片 |
| **光图每片纹素** | **2.8 px** |
| 屏幕每片像素 | **35.8 px**（截图实测 430×430px 区域） |
| **差距** | **12.8 倍** |

**结论**：光图一个翅片只有 2.8 个纹素，装不下「正面 / 侧面 / 缝隙」三层明暗。
屏幕上每片有 35.8 像素的空间，但光图给不出对应信息。
**这不是数据错误，是信息量不足 —— 补光图数值无法突破。**

### 为什么之前几版都没成功

| 版本 | 做法 | 结果 |
|---|---|---|
| v1 | 加固定常数 | 过曝，5988 个纯白像素 |
| v2 | 按差距补齐 | 误伤正常背光暗部 |
| v3 | 只补真黑 → 填常数 | **不黑了，但整块同值 → 哑光白板** |
| v4（当前） | 方向图结构调制 | 有梯度（std 0.0733），但受 33px 上限约束，细节仍不足 |

## 三、2F 为什么"看着正常"

1. **68 盏 Area 光全部是 Mixed 模式**（Type=3, Lightmapping=2）
   → Play 模式下仍在实时计算漫反射 + 高光，给暖气补出层次
2. **场景模式没有这份实时补光** → 所以 2F 在场景模式同样是黑的（用户截图证实）
3. 2F 暖气是薄板型（0.95×0.83×0.09 无翅片），细节需求低于 1F 翅片型
