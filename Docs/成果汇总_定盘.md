## 二、功能成果（五大模块 + 两套引擎）

### 1. 管理系统五大模块（全部打通，判据 178/178）

| 模块 | 能力 |
|---|---|
| 数据监测 | 363 点位实时状态、数值读数、趋势 |
| 设备管理 | 台账 / 搜索 / 类型+楼层双排筛选 / 详情卡 |
| 电力管理 | TwinCircuit **20 节点三级回路**，开关返回影响设备清单 |
| 告警中心 | 四级告警、点告警定位设备 + 全链路时间线 |
| 数据统计 | 按 Category/Zone 聚合、Top5 能耗排名、数据源标识 |

> 口径：P00 v1.29 裁决——**模块数为五，不是六**。天气是底层仿真引擎，与管理模块不在同一层。

### 2. 昼夜天气仿真引擎（独立系统，非第六模块）

- **15 分钟压缩 24 小时**昼夜循环（比原神 24 分钟快 1.6 倍）
- 7 档天气 + 随机转移链，晴/多云/阴/雨/暴雨/雾/雪随昼夜演变
- 天空/光照/环境色 **2.4 秒平滑过渡**（非硬切）
- 雨雪粒子：距离场解析散射提亮、恒定终端速度下落、室内外判定剔除
- 时间天气双通道：数据侧 `TwinClimate` + 视觉侧 `EnvironmentState`，由 `TwinWeatherBridge` 统一收口

### 3. 场景交互引擎

- **17 个场景交互点**（走近触发），3 类菜单驱动器（通用 / PC / 饮水机）
- 三态相机：第一人称漫游 / 第三人称 / 观景俯视
- 43 个点位接入受控白名单，支持开关命令 + 回读确认

## 五、性能现状（如实）

| 场景 | 帧率 |
|---|---:|
| 灯光未生效基线（黑暗场景）| 36.6 fps |
| 完整光照体系开启 | **7.2~8.4 fps**（编辑器 + 桥接开销，仅供量级参考）|
| 单帧耗时 | GPU 108~198 ms / CPU 94~244 ms |

> 瓶颈定位：巨型合并网格的逐像素 pass + 48 盏 ForcePixel 预算，非灯数本身（洗顶 41→22 无收益已实测）。
> 根治方案：洗顶层烘焙 lightmap（D13 有旧烘焙数据不可用前科，需重核夜间照度）。
> **最终以打包实测为准**，编辑器带桥接的帧数不代表交付性能。
