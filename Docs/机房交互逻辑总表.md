# 机房（计算机教室）交互逻辑总表

> 维护者：断点（unity-csharp-dev）
> 最后更新：2026-11-02
> 适用场景：1 号教学楼 1F 计算机教室（Zone = `ClassComputer`）

---

## 一、设备清单（这是所有逻辑的前提）

| 角色 | TwinId | 数量 | 说明 |
|---|---|---|---|
| 主脑 | `ClassComputer/PC/Master_01` | 1 | 讲台那台，**只代表自己** |
| 学生机 | `ClassComputer/PC/Seat_01` … `Seat_18` | 18 | 场景里实际建出来的独立点位 |
| 投影仪 | `ClassComputer/Projector/Main_01` | 1 | 幕布 + 机身 |
| ~~机房聚合点位~~ | ~~`ClassComputer/PC/Room_01`~~ | **0** | **场景里不存在这个锚点** |

### ⚠️ 最重要的一条前提

`Room_01` 在白名单（`TwinControlScope`）里，但**场景里没有对应锚点**。

后果：
- 任何 `Send("ClassComputer/PC/Room_01", ...)` 都会被命令中心拒绝
- 任何 `Registry.TryGet("ClassComputer/PC/Room_01")` 都会失败

所以**所有"机房整体"的操作必须遍历 18 个 Seat**，不能发一条 Room 命令。

> 历史教训：2026-11-01 之前的"联动开机"就是发 `Room_01`，结果只有主脑和投影有反应。

## 二、视觉资源（3 个播放器 + 4 类素材）

### 播放器

| 播放器 | 归属 | 输出 | 谁在用 |
|---|---|---|---|
| 主脑播放器 | `Master_01` 的 `ScreenVisual.Player` | 主脑那 1 块屏 | 主脑 |
| 投影播放器 | `Projector/Main_01` 的 `ProjectorVisual.Player` | 幕布 | 投影 |
| **机房播放器** | `_roomPlayer`（不挂任何 Renderer） | 1 张 RT | **18 个 Seat 共用** |

机房播放器的实现见 `TwinDevicePresenter.RoomScreenPlayer()`：
- 懒创建，模板材质复制自主脑那份（着色器配置一致）
- 创建后立刻 `SetOn(true) + PlayFile(_roomVideo)` **预热**，否则第一次开机的头几台会黑屏
- 成本：1 个 `VideoPlayer` + 1 张 RT（不是 18 个）

### 素材

| 素材 | 常量 | 用途 |
|---|---|---|
| `master/boot.mp4` | `PcMediaLibrary.Boot` | 开机动画 |
| `master/shutdown.mp4` | `_shutdownVideo` | 关机动画 |
| `master/desktop.jpg` | `PcMediaLibrary.Desktop` | 开机完成后的桌面（待机图） |
| 运行时快照 | `_seatSnapshot` | 座位被"摘下"时用的静态桌面图 |

## 四、交互菜单状态机（`TwinPcMenuDriver.BuildItems`）

| state | 条件 | 显示项 |
|---|---|---|
| **5** | 关机动画播放中 | 「正在关机…」（不可点） |
| **3** | `_playMode == Ppt` | 上一页 / 下一页 / 退出PPT |
| **4** | `_playMode == Video` | 切换 / 暂停 / 退出视频 |
| **0** | 主脑关 且 无座位开着 且 投影关 | 开机 / 联动开机 / 投影 |
| **2** | 主脑关 但 有座位或投影开着 | 全部关机 / 联动开机 |
| **1** | 主脑开 | 打开PPT / 视频播放 / 关闭主脑 / 全部关机 |
| **断电** | `!TwinCircuit.IsPowered(Master)` | 「电脑已断电 · 无法操作」（最优先，盖过以上全部） |

> `state` 判定里用的是 `AnySeatOn()`，**不是** `IsOn(Room_01)`——后者恒为 false。

## 五、每个交互的完整链路

### 1. 开机（state 0）

```
Send(Master_01, SetPower(1))
  → MockDeviceAgent.ApplyState → Power=180, OnCount=1
  → TwinDevicePresenter.SyncScreen(Master_01) → on=true
  → ApplyScreen：单屏分支 → 播 master/boot.mp4
```

**影响范围：只有主脑 1 块屏。** 18 台座位、投影都不动。

---

### 2. 联动开机（state 0 / 2）

```
① Send(Master_01, 1)          → 主脑开机
② Send(Projector, 1)          → 投影开机
③ 0.35s 后 SendRoom(true)     → 遍历 18 个 Seat，逐条 SetPower(1)
```

`SendRoom` 内部：

```csharp
foreach (var a in TwinDeviceStats.AllDevices)
    if (a.TwinId.StartsWith("ClassComputer/PC/Seat_"))
        Send(a.TwinId, 1f, "联动开机（机房）");
```

视觉链路（每个 Seat）：

```
ApplyScreen(seat, true)
  → RoomScreenPlayer()（进 Play 就预热，RT 里已经是桌面图）
  → v.Material._EmissionMap = roomPlayer.ScreenRT
  → FadeAt = now + (序号-1) × 0.07s
  → TickScreenStagger 到点渐亮（0.25s）
```

**观感**：主脑 + 投影播开机动画，18 台在 1.26 秒内陆续亮起、**一起播开机动画**。

> **联动开机和单台开机的区别只在"要不要摘别人"**
>
> `TwinPcMenuDriver.SendRoom(true)` 会先调 `BeginBulkSeats()` 打开 1.5 秒窗口：
>
> | 场景 | `Time.time < _bulkSeatUntil` | 动作 |
> |---|---|---|
> | 联动开机（窗口内） | true | **不摘别人** → 18 台都接机房 RT → 一起播开机动画 |
> | 面板单点一台（窗口外） | false | `DetachSeatScreens(自己)` → 只有这一台接 RT 播动画 |
>
> 不开窗口的话，第一个处理的座位会把其他 17 台摘成静态快照，
> 变成"只有一台播动画、其余是桌面"。

---

### 3. 投影（state 0）

```
Send(Master_01, 1) + Send(Projector, 1)
```

语义：开主脑 + 开投影（不带机房）。

---

### 4. 关闭主脑（state 1）

```
BeginShutdown(onComplete, includeRoom = false)
  → DetachSeatScreens()          ← 18 台切到桌面快照
  → 主脑播放 shutdown.mp4 → 灭
  → 投影播放 shutdown.mp4 → 灭
  → onComplete：Send(Master_01, 0)
```

**影响范围：主脑 + 投影。** 18 台座位**保持桌面**（不播关机动画、不变黑）。

> 为什么不带机房：机组没关却先演一遍"正在关机"再亮回来，不符合现实。

---

### 5. 全部关机（state 1 / 2）

```
BeginShutdown(onComplete, includeRoom = true)
  → RestoreSeatScreens()         ← 18 台接回机房 RT
  → 主脑：if (IsOn) 播 shutdown.mp4 → 灭
  → 投影：if (IsOn) 播 shutdown.mp4 → 灭
  → 机房播放器：无条件 SetOn(true) + PlayFile(shutdown.mp4)
        → 18 台跟着播 → 各自渐暗灭
  → ForceScreensOff(true)：关主脑 / 投影 / 机房播放器
  → onComplete：Send(Master_01, 0) + SendRoom(false) + Send(Projector, 0)
```

**关键：机房播放器不判 `IsOn`。** 它代表 18 台，不是某一块屏；判 `IsOn` 的话第二次全部关机就播不出来。

**已关的设备会跳过**（主脑/投影 `IsOn == false` 时不播），避免"关了的设备又亮一下"。

---

### 6. 打开 PPT（state 1）

```
EnsureProjectorOn()          ← 投影没开就开（幕布是 PPT 的目标）
DetachSeatScreens()          ← 18 台切桌面快照
EnterPptMode()
  → CollectPptTargets() = 主脑材质 + 投影幕布材质   ← 只收这两个
  → _playMode = Ppt
  → _slideShow.Show(0)
```

**18 台座位不参与 PPT**（保持桌面）。

---

### 7. 视频播放（state 1）

同 PPT，走 `EnterVideoMode()`：
- `DetachSeatScreens()` → 18 台桌面快照
- 主脑 + 投影播视频
- `_playMode = Video`

---

### 8. 退出 PPT / 视频

```
ExitPptMode() / ExitVideoMode()
  → RestoreIdleScreen()        ← 主脑/投影贴 desktop.jpg
  → RestoreSeatScreens()       ← 18 台接回机房 RT
  → 销毁 _seatSnapshot
```

---

### 9. 面板单台开机

```
TwinControlRow.Send(SetPower, 1) / TwinControlPanel.SendPower(row, true)
  → TwinCommandCenter.TrySend(Seat_XX, SetPower, 1)
  → ApplyState → Power=180, OnCount=1
  → SyncScreen(Seat_XX) → on=true
  → ApplyScreen：Seat 分支
        if (!AnyOtherSeatOn(本台))          ← 整间只有它开
              roomPlayer.ShowStill(Desktop)  ← 先给桌面（不黑屏）
              roomPlayer.PlayFile(boot.mp4)  ← 后台准备开机动画
        map = roomPlayer.ScreenRT
        FadeAt = now + (序号-1) × 0.07s → 渐亮 0.25s
```

**两种情况**：

| 场景 | `AnyOtherSeatOn` | 是否播开机动画 |
|---|---|---|
| 整间关着，点一台 | false | **播**（先桌面 → 1~2 秒后出开机动画） |
| 联动开机（18 台同帧置 1） | true | **不播**（都显示桌面） |

判据读的是**数据层的 Power**，不是视觉层的 `IsOn`——联动时 18 台数据同帧更新，
视觉遍历到第一台时其他台的数据已经是 180W，所以能正确识别为"联动"。

**只影响这一台。** 其他座位的材质不变。

---

### 10. 面板单台关机

```
TwinControlRow.Send(SetPower, 0) / TwinControlPanel.SendPower(row, false)
  → 检测到是 Seat 且要关机
  → TwinDevicePresenter.BeginSeatShutdown(twinId, onComplete)
        DetachSeatScreens(exceptTwinId = 本台)   ← 其他开着的座位切快照
        机房播放器 PlayFile(shutdown.mp4)        ← 只有本台（还接 RT）跟着播
        等播完 / 超时（8s）
        机房播放器 PlayFile(boot.mp4)            ← 切回开机视频
        onComplete：Send(Seat_XX, SetPower, 0) → 本台渐暗灭
```

**关键：`exceptTwinId` 排除本台。** 18 台共用一张 RT，不排除的话点一台关机，其他 17 台也会播关机视频。

## 六、组合矩阵（前置状态 × 操作 → 结果）

| 前置状态 | 操作 | 主脑 | 投影 | 18 台座位 |
|---|---|---|---|---|
| 全关 | 开机 | 亮 | — | — |
| 全关 | 联动开机 | 亮 | 亮 | 陆续亮 |
| 全关 | 投影 | 亮 | 亮 | — |
| 主脑开 | 关闭主脑 | 关机动画→灭 | 关机动画→灭 | **不动（桌面）** |
| 主脑开 | 全部关机 | 关机动画→灭 | 关机动画→灭 | **播关机动画→灭** |
| 主脑开 | 打开 PPT | 幻灯片 | 幻灯片 | **不动（桌面）** |
| 主脑开 | 视频播放 | 视频 | 视频 | **不动（桌面）** |
| PPT 中 | 退出 PPT | 桌面 | 桌面 | 恢复桌面 |

## 七、状态依赖关系（改代码前必看）

```
_playMode (None/Ppt/Video)
    ↓ 决定菜单显示哪一组按钮
    ↓ 决定主脑/投影贴什么

mp.IsOn / pp.IsOn          ← 决定关机动画播不播
_roomPlayer.IsOn           ← 不参与判断（无条件播）

_seatSnapshot              ← 非 null 表示座位处于"摘下"状态
    摘下 = 贴静态桌面图，不跟随机房 RT
    接回 = 贴机房 RT，跟随视频

v.IsOn（每个 Seat）         ← 决定渐亮/渐暗、以及 Detach 时跳不跳过
```

### Detach / Restore 配对表

| 调用点 | 用哪个 | 原因 |
|---|---|---|
| `ShutdownRoutine(includeRoom=false)` | `DetachSeatScreens()` | 只关主脑，座位不该跟着黑 |
| `ShutdownRoutine(includeRoom=true)` | `RestoreSeatScreens()` | 全部关机，座位要播关机动画 |
| `EnterPptMode` | `DetachSeatScreens()` | PPT 只投主脑+幕布 |
| `EnterVideoMode` | `DetachSeatScreens()` | 视频只放主脑+幕布 |
| `ExitPptMode` | `RestoreSeatScreens()` | 恢复座位 |
| `ExitVideoMode` | `RestoreSeatScreens()` | 恢复座位 |
| `BeginSeatShutdown` | `DetachSeatScreens(exceptTwinId)` | 只让目标台播关机动画 |

**新增入口时必须问自己：这一步之后，座位应该"跟着机房 RT"还是"定格"？** 选错就是新一轮 bug。

## 八、已知边界与副作用

| 项 | 现状 | 说明 |
|---|---|---|
| 18 台开机动画 | **有**（联动和单台都有） | 共用一张 RT，同步播同一段；单台开机会先摘掉其他座位防串台 |
| 视频 Prepare 延迟 | 先贴桌面图再播 | `PlayFile` 异步，1~2 秒才出第一帧；先 `ShowStill(Desktop)` 保证不黑屏 |
| 单台关机后其他座位 | 定格在桌面快照 | 它们状态还是"开机"，显示桌面合理 |
| 机房播放器常驻 | `_on` 常为 true，不随关机熄灭 | 它是"画面来源"不是"某块屏"；关掉会让下次开机重新 Prepare 而黑屏 |
| `Room_01` 相关代码 | 保留但走不到 | 若以后补回锚点，`MergeUnits`/`SyncUnitsEmissionMap` 会自动生效 |
| 座位屏 draw call | 18 个独立材质 | 无法合批，换单台可控 |
| 快照分辨率 | 跟随 `_roomVideoAtlasSize`（默认 512） | 内存约 0.75MB |
