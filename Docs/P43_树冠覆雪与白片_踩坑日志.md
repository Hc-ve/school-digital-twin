## 二、七个坑（按踩的时间顺序）

### 坑 1 · 新建 shader 用 `scope=scripts` 刷新不会导入
- **现象**：shader 文件在磁盘上，但 `Shader.Find` 返回 null，只建出 mesh、不建物体。
- **根因**：MCP 刷新资源时 `scope=scripts` 不覆盖 `Resources/` 下的 shader 导入。
- **正解**：`scope=all`。
- **复用判据**：凡是新增非脚本资源（shader / mat / prefab），刷新一律 `scope=all`；`scope=scripts` 只适合改 `.cs`。

### 坑 2 · 整冠雪被变成"白帆布"
- **现象**：整棵树冠被一块均匀白布糊住，没有斑块感。
- **根因**：shader 里 mask 用了**加法噪声**，树冠顶部的 mask 恒大于阈值 → 几乎不裁形。
- **正解**：改成**乘法噪声**才有斑块感。
- **复用判据**：需要"局部镂空/斑驳"的 mask，用乘法而不是加法——加法只会整体抬高，永远裁不出洞。

### 坑 3 · 雪只加在独立克隆树，35 棵主树走 Terrain 路径
- **现象**：改完只看到零星几棵树有雪，主体树全没反应。
- **根因**：场景树分两条路径——独立克隆树 vs Terrain 树（35 棵）。雪逻辑只挂了前者。
- **状态**：本轮未解（属搁置支线的一部分）。
- **复用判据**：改"所有树/所有同类物体"前，先枚举一遍到底有几条生成路径，别假设场景里只有一种。

### 坑 4 · 雪帽定位三连坑
1. 用格内最远点 → 挂在冠中下部，像**白蘑菇**；
2. 改格内最高点 → 被叶幕**全遮住**；
3. 最终正解 → **按方位角取最外缘叶尖**才露出来。
- **复用判据**：往树冠上挂东西，"最高点"和"最远点"都不是可见点，**外缘**才是。

### 坑 5 · 雪片外推 0.45r → 大片悬空白纸
- **现象**：实拍出现大片悬在空中的白纸片。
- **根因**：外推系数 0.45r 太大，雪片脱离枝梢。
- **正解**：收回 **0.02r** 并恢复密度门，才贴住枝梢。
- **复用判据**：贴附类几何的外推量从**极小值起步**（0.02r 级别），大外推必然出现悬浮。

### 坑 6 · CS7036（调用漏参数 `ft`）导致无法进 Play
- **现象**：编译报错，Play 进不去。
- **正解**：补参数 + `scope=all` 刷新恢复。
- **复用判据**：常规编译错误，记录是为凑齐"这轮为什么反复卡在编译"的完整链条。

### 坑 7 · 【核心】烘焙预制体路径优先 —— 白片改完没消失
- **现象**：`SnowOnRoofs.cs` 加了排除名单后，白片纹丝不动；误以为是编译问题，反复核对 DLL 时间戳。
- **根因链**：
  1. `SnowOnRoofs.cs` 的"逐列最高朝上面"判据把二楼楼板 `Floor2`（顶面 y≈7.94）误判成屋顶，铺了雪壳；
  2. 但真正渲染出来的雪壳来自**烘焙预制体 `RoofSnowBake.prefab`**，运行时扫描路径根本没执行；
  3. 所以改运行时的排除名单 = 白改。
- **正解（两处都改）**：
  - `SnowOnRoofs.cs` 新增 `excludeSourceName` 排除名单（`Floor2` / `KitchenFloor` / `ZalTop` / `ZalStairs`）；
  - 烘焙路径按名字剔除并销毁该片；
  - `RoofSnowBakeTool.cs` 同步加同一份名单，防止重跑烘焙又把室内楼板收进去。
- **验收**：雪壳 27→26 片，Floor2=0，二楼地面露出原灰蓝材质。
- **复用判据（最重要）**：
  > **双路径功能（烘焙产物 + 运行时扫描）：先确认当前走的是哪条，再动手。**
  > 有烘焙 prefab 时，默认假设烘焙路径优先。
  > "改了没生效"的排查顺序应是：① 路径是否执行 → ② 是否被上层覆盖 → ③ 最后才是编译/DLL。

## 三、可复用清单（下次直接照做）

1. 新增非脚本资源 → MCP 刷新用 `scope=all`。
2. 斑驳/镂空 mask → 乘法噪声，不用加法。
3. 改"所有 X"前 → 先枚举 X 的所有生成路径（本例：克隆树 vs Terrain 树）。
4. 树冠挂件定位 → 按方位角取外缘，不用最高点/最远点。
5. 贴附几何外推 → 从 0.02r 极小值起步。
6. 双路径功能 → 先定当前执行路径，烘焙产物优先怀疑。
7. "改了没生效" → 路径 → 覆盖 → 编译，按这个顺序查。
