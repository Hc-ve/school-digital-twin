## 6. 验收标准（可量化，挑刺按此回归）

1. **横向**：左轨 168 + 间隙 16 + 右区 440 + 右边距 16 = 640，四段测量误差 ≤1px。
2. **纵向**：每页最后区块下沿 ≤528（按 §5 表逐页核，允许 ±1px）。
3. **占位可辨**：数据统计页与告警追溯区取样，占位区内部与面板底 Δ ≤ 2（确认无渐变底）；占位区文字取样为 `#75859C`。
4. **无假数据**：数据统计页除三点进度外不出现任何数字；`grep` 代码中该页无图表类调用。
5. **摘要**：数据监测页只显示 `受控 N`；其余四页显示三项且顺序为 在线→告警→受控；右端 x 与 × 命中区左端间距 ≥12px。
6. **Tab 三件套**：选中项同时具备 AccentDim 底 + 左 3px 竖条 + `#F0F5FC` 文字，缺一即不合格。
7. **Top3 文案**：状态标签为「进行中」，**不出现**「严重/警告」字样。
8. **工具行**：L1 与 L2 逐像素一致（沿用 P29-2 的 33600 像素比对法，最大差值 ≤8）。
