## 0. 老师规则（11-04 主理人转述，硬约束）

1. 一组答辩**只能展示一个项目**（= 本校园数字孪生项目）。
2. 答辩内容**必须与该项目有关**，**不得出现口径不一致**。
3. ⇒ 队员个人项目**不进 PPT、不上台讲**（原 B 档 16B 页方案作废，裁决 C-51）。
4. 每名队员必须能说出「**我为这个项目贡献了什么**」——贡献 = 下表分配的真实职责与产物。

## 2. 每人答辩口径（现场被问「你负责什么」时照此答，3 句以内）

- **老大**：「我负责整个系统的架构和核心开发，从孪生框架到五个管理模块，以及数据真实性专项。PPT 和实习报告也由我完成。」
- **杨续**：「我负责天气系统。雨雪粒子、天空、地面积雪和积水全部是代码程序化生成的，没有用任何外部素材；这周我和组长一起把它融合进了主项目。」
- **王绍锋**：「我负责测试回归。项目有 273 条自动判据，我逐条跑过并做了 play 回归，回归记录和 bug 台账在我这里。」
- **张俊才**：「我负责现场演示和应急。演示动线我排练过两遍，断网、投影仪比例、程序崩溃三种意外都有处置卡。」
- **赵朕**：「我负责数据口径核对。PPT 和讲稿里出现的每个数字，我都对照项目基线逐项核验过，核对表在我这里。」
- **王雯信**：「我负责项目文档整理。使用手册初稿和全部素材的归档命名是我做的。」
- **李文玉**：「我负责演示视频。素材由组长录制，剪辑、字幕和解说词是我做的。」

**统一兜底话术**（被问到不熟的细节时）：「这块的技术实现是组长做的，我负责的是 XX（自己的一句话职责），细节他可以补充。」
