> 三处必须逐字使用本表的「标准职责表述」，**不允许各自发挥**（老师要求口径一致）。

## 0. 硬约束（11-04 老师规则）

1. 一组答辩**只能展示一个项目**（= 本校园数字孪生项目）。
2. 答辩内容**必须与该项目有关**，**不得出现口径不一致**。
3. ⇒ 队员个人项目**不进 PPT、不上台讲**（裁决 C-51）。
4. 每名队员必须能说出「我为这个项目贡献了什么」= 下表职责 + 对应产物。
5. 实习报告**由各成员本人撰写**（依据本表口径与自己的产物），不列入组长职责。

## 0.1 分工设计原则（内部掌握，不上台念）

- 职能域共 8 块：项目管控与核心系统 / 天气系统 / UI 设计 / 场景资产与视觉 /
  设备交互 / 质量与打包 / 项目文档 / 演示制作。核心系统与管控归组长（60%），其余 40% 分给六名队员。
- 每人职责与其**个人项目的技能背景对口**，被追问「你为什么负责这块」时答得顺：
  赵朕做过内置管线孪生+UI → UI 设计；张俊才做过第一人称漫游场景 → 场景资产；
  王绍锋做过教室控制台（空调/摄像头交互、CCTV）→ 设备交互与视觉调优；
  李文玉做过完整交互仿真交付 → 演示制作与交互调研；王雯信做过文档自动化流水线 → 日志归档与打包；
  杨续是天气包**实际作者** → 天气系统（真贡献）。
- 每条职责都挂着项目里**真实存在的产物**（设计稿/修复记录/判据/打包产物/文档/视频）。
- 「参与设备交互开发」口径的成立依据：门（12 点位）、灯（16 点位）、空调（5 点位）等基础交互
  在各成员个人项目中均已独立实现过，本项目中承担同类交互的实现与联调。

## 4. 实习报告口径

- 各成员依据本表 §2 口径 ＋ §3 自己的产物**本人撰写**。
- 「实习内容」段 = 一句话职责 ＋ 产物清单 ＋ 2~3 句过程描述；
  「实习收获」段围绕自己职责域写（UI 的人写先图后码、场景的人写烘焙光照排查、打包的人写多分辨率适配……）。
- **禁止**在实习报告里写个人项目（与答辩口径一致，老师会对照）。
