## 1. 杨续：为什么只融天气，不融其余

他的项目与本项目**同场景、同引擎版本**，README 质量全组最高（46 条踩坑、逐文件行数、可拆模块分级）， temptation 很大。逐模块核过：

| 他的模块 | 不融合的理由 |
|---|---|
| 交互框架 B 组（门/灯/座椅自动挂载 + 仲裁，1,025 行） | 本项目已有自己的控制链路（`TwinPicker` / `TwinInteractMenu` / `TwinDevicePresenter` / SBO / 回路断电），并入第二套交互仲裁 = 两套"谁管谁"打架，正是基线 F 类 16 条踩坑的源头 |
| 第一人称控制器 + 双模式切换 | 本项目已有第三人称/第一人称/观景三态（`TwinThirdPersonCamera` + V 键），再并一套 `CampusModeManager` = 相机控制权三方争夺 |
| UI 视觉规范 C 组（UIStyle/UITheme 鎏金系） | 与本项目科技蓝 token 体系（`TwinTheme`）直接冲突，C-48 刚裁过主色口径 |
| 数字孪生大屏 D 组 | 强绑定他的 POI/设备数据模型，与 `TwinDeviceStats` 口径冲突 |

**但他的踩坑日志是本项目当前最值钱的外部输入**：§10.2 天空与天气 9 条坑与断点正在修的雨雪 bug 同根（已单独转交，见 `P13` 补充材料包）。§10.1 的 URP 材质坑（品红/发白/Cutout 丢失）对本项目内置管线无直接适用，但坑 7「VolumeProfile 组件引用 fileID:0 = 后处理静默失效」与本项目 C-46（P30 后处理死路）**同型**，佐证了我们的裁决方向。

## 2. B 档六页怎么进 PPT（**⚠️ 11-04 18:40 作废，见下**）

- 每人**一个 tile**，汇总成一页「组员独立项目成果一览」（加在 PPT 第 16 页分工页之后，编号 16B）：姓名 / 项目一句话定位 / 一个最有亮点功能 / 一张截图。
- **答辩时本人讲自己的 tile**（30~60 秒），讲自己做的东西不会露怯。
- 杨续例外：他的天气已并入主项目，讲 PPT 第 09 页（天气系统页），tile 里写「天气系统作者，见第 09 页」。
- 口径红线（写进每页备注）：**tile 内容如实标注为「组员个人项目」，不得表述为统一答辩项目的功能**。评委 play 的只有本项目，tile 上的功能 play 不到，标注清楚就不构成虚假陈述。
