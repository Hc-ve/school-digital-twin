## 二、细节验收

### 2.1 主脑显示器
- [ ] 画面**铺满**屏幕（不留黑边）
- [ ] 显示器**白色边框不发光**（只有屏幕区域亮）
- [ ] 画面比例正确，不变形
- [ ] 有声音（3D 音源，走近更响）

### 2.2 机房 18 台
- [ ] 一进 Play 全黑（不是全亮）
- [ ] 联动开机时**逐台点亮**，不是一起亮
- [ ] 点亮顺序是从房间一侧扫到另一侧（不是乱跳）
- [ ] 全部点亮后画面与主脑同步

### 2.3 投影幕布
- [ ] 幕布显示画面，**左右方向正确**（和显示器一致，不镜像）
- [ ] 画面**铺满**幕布，无黑边、无残缺
- [ ] 有**暗角**（四角比中心暗）
- [ ] 整体略偏暖（不是死白）
- [ ] 幕布周围的墙/天花板被照亮
- [ ] 能看到**光柱**从投影仪射向幕布
- [ ] 关机后幕布变回**浅灰白的布**，不是黑板
- [ ] 主脑关机后幕布变黑（无信号），不是冻在最后一帧

### 2.4 面板
- [ ] 按钮尺寸统一（220×44）、间距 10、圆角 22
- [ ] 五个状态切换正确（见上方五态对照表）
- [ ] 播放模式下**看不到**「全部关机」「关闭主脑」
- [ ] PPT 模式按钮显示页码（如 `下一页 3/12`）
- [ ] 视频模式按钮显示序号（如 `切换 1/2`）
- [ ] 暂停后按钮变「继续」
- [ ] 离开范围面板淡出
- [ ] 面板不遮挡视线（在左侧偏中）

### 2.5 PPT 模式
- [ ] 点「打开PPT」后主脑 + 幕布**同时**显示第 1 页
- [ ] 文字**完整**、不被裁边（这是 contain 模式的意义）
- [ ] 「下一页」翻到底会**循环**回第 1 页
- [ ] 「上一页」在第 1 页会跳到最后一页
- [ ] 退出后屏幕回到开机画面，不是黑屏
- [ ] 幕布上 PPT 有暗角（保持投影质感）

### 2.6 视频模式
- [ ] 点「视频播放」开始播第 1 个
- [ ] 「暂停」画面冻住但**屏幕还亮**
- [ ] 再点「继续」从冻住处接着播
- [ ] 「切换」循环切到下一个视频
- [ ] 退出后屏幕回到开机画面

### 2.7 关机动画
- [ ] 点「全部关机」→ 屏幕**先播关机动画**，不是瞬间黑
- [ ] 动画约 4 秒，播完才真正黑掉
- [ ] 动画期间面板显示「正在关机…」，点不动
- [ ] 「关闭主脑」同样先播动画（机房 18 台不受影响）
- [ ] 主脑和幕布**同时**播同一段关机动画

## 三、已知限制（不是 bug）

| 项 | 说明 |
|---|---|
| 幕布画面裁边 | 视频 1.96:1，幕布 1.47:1 → cover 会裁掉两侧各约 12% |
| `ppt.mp4` / `lesson.mp4` | 目前是 **ffmpeg 生成的占位图**（纯色 + 文字），放真素材即可替换 |
| 18 台 draw call | 逐台独立材质会破坏静态合批，18 台 = 18 个 draw call（可接受） |
| 投影光柱 | 是加法混合的面片，从某些角度看会偏淡 |

## 四、素材替换方法

```
Assets/StreamingAssets/PC/
├── master/
│   ├── boot.mp4              开机动画（主脑 + 18 台 + 幕布共用）
│   └── shutdown.mp4          关机动画（点关机时先播，播完才断电）
├── ppt/                      PPT 图片，一页一张
│   ├── slide_01.jpg
│   ├── slide_02.jpg
│   └── …                     （当前 12 页，1920×1200，合计 1.4MB）
└── videos/                   视频播放列表
    └── 01_数字孪生科普.mp4     （当前 1 个，134 秒，35MB）
```

### PPT 怎么加/换

**方法一：PDF → 图片（推荐）**
```bash
python tools/p26_ppt2img.py 你的PPT.pdf
```
自动输出 `slide_01.jpg … slide_NN.jpg` 到 `PC/ppt/`，
规格 1920×1200、16:9 内容居中 + 上下黑边。

**方法二：手工放图**
直接把 JPG/PNG 丢进 `PC/ppt/`，**文件名用数字前缀**（`slide_01`、`slide_02`…）——
代码按文件名排序，前缀决定页序。

### 视频怎么加/换

把 mp4 丢进 `PC/videos/`，**文件名用数字前缀**（`01_xxx.mp4`、`02_xxx.mp4`…）。

用 `tools/p26_import.sh` 转码：
```bash
./tools/p26_import.sh 新视频.mp4 videos/02_新内容.mp4
```

### 素材规范
1. 分辨率建议 1920×1200（16:10）
2. **不能带黑边** —— 先跑一遍检测：
   ```bash
   ffmpeg -i 新素材.mp4 -vf "cropdetect=limit=24:round=2:reset=0" -f null -
   ```
   输出必须是 `crop=W:H:0:0`
3. PPT 图片保持 16:9 内容 + 上下黑边（脚本会自动做）
4. 有声音的素材会走 3D 音源（从机房音箱出声）

## 五、可调参数速查

在 `TwinDevicePresenter` 组件面板上：

| 参数 | 默认 | 作用 |
|---|---|---|
| `_screenStagger` | 0.15 | 逐台点亮间隔（秒），0 = 同时全亮 |
| `_projectorVignette` | 0.30 | 投影暗角强度，0 = 像 LED 屏 |
| `_projectorMaxBright` | 0.92 | 投影最高亮度，1.0 = 更亮 |
| `_projectorWarmth` | 0.12 | 灯泡色温，正暖负冷 |
| `_beamIntensity` | 2.4 | 投影聚光灯强度 |
| `_beamConeAlpha` | 0.30 | 光柱不透明度 |
| `_projectorFollowMaster` | true | 幕布是否跟随主脑开关 |
| `_screenVideoInset` | 0 | 屏幕画面内缩（0 = 铺满） |
| `_debugScreenQuad` | false | **调试**：幕布染亮红，确认改的是哪块模型 |

## 六、出问题时看哪里

```bash
LOG="C:/Users/<user>/AppData/Local/Unity/Editor/Editor.log"

# 只看最新一次编译的错误（过滤历史噪音）
n=$(grep -an "Begin MonoManager ReloadAssembly" "$LOG" | tail -1 | cut -d: -f1)
awk -v s="$n" 'NR>s' "$LOG" | grep -a "error CS" | sort -u

# 只看最新一次运行的 P26 日志
awk -v s="$n" 'NR>s' "$LOG" | grep -a "\[P26\]" | tail -30
```

### 常见症状对照

| 症状 | 看这行日志 | 病因 |
|---|---|---|
| 屏幕不亮 | `SetOn(True) → playing=? prepared=? frame=? blit=?` | `blit` 不涨 = 合成没跑；`playing=False` = 播放器没起来 |
| 幕布黑但显示器正常 | `幕布改用模型本体作载体：… （原材质槽 N 个）` | N 必须是 ≥1；若这行没出现 = `TryGetScreenFrame` 判定不像屏幕 |
| 幕布镜像 | `法线 (x, y, z)` | 法线轴决定 `right`，若镜像说明叉积符号问题 |
| 逐台点亮不生效 | `… 逐个亮=0.15s/台` | 这行没出现 = `hits.Count <= 1` 或 `_screenStagger = 0` |
| 换片没反应 | `切视频 → …` / `找不到视频「…」` | 后者会附上目录路径和现有文件列表 |
