## 二、细节验收

### 2.1 主脑显示器
- [ ] 画面**铺满**屏幕（不留黑边）
- [ ] 显示器**白色边框不发光**（只有屏幕区域亮）
- [ ] 画面比例正确，不变形
- [ ] 有声音（3D 音源，走近更响）

### 2.2 机房 18 台
- [ ] 一进 Play 全黑（不是全亮）
- [ ] 联动开机时**逐台点亮**，不是一起亮
- [ ] 点亮顺序是从房间一侧扫到另一侧（不是乱跳）
- [ ] 全部点亮后画面与主脑同步

### 2.3 投影幕布
- [ ] 幕布显示画面，**左右方向正确**（和显示器一致，不镜像）
- [ ] 画面**铺满**幕布，无黑边、无残缺
- [ ] 有**暗角**（四角比中心暗）
- [ ] 整体略偏暖（不是死白）
- [ ] 幕布周围的墙/天花板被照亮
- [ ] 能看到**光柱**从投影仪射向幕布
- [ ] 关机后幕布变回**浅灰白的布**，不是黑板
- [ ] 主脑关机后幕布变黑（无信号），不是冻在最后一帧

### 2.4 面板
- [ ] 按钮尺寸统一（220×44）、间距 10、圆角 22
- [ ] 三个状态切换正确：
  - 全关 → 开机 / 联动开机 / 投影
  - 主脑开 → 打开PPT / 视频播放 / 关闭主脑 / 全部关机
  - 主脑关但机房还开 → 全部关机 / 联动开机
- [ ] 离开范围面板淡出
- [ ] 面板不遮挡视线（在左侧偏中）

## 三、已知限制（不是 bug）

| 项 | 说明 |
|---|---|
| 幕布画面裁边 | 视频 1.96:1，幕布 1.47:1 → cover 会裁掉两侧各约 12% |
| `ppt.mp4` / `lesson.mp4` | 目前是 **ffmpeg 生成的占位图**（纯色 + 文字），放真素材即可替换 |
| 18 台 draw call | 逐台独立材质会破坏静态合批，18 台 = 18 个 draw call（可接受） |
| 投影光柱 | 是加法混合的面片，从某些角度看会偏淡 |

## 四、素材替换方法

把 mp4 丢进 `Assets/StreamingAssets/PC/master/`，**文件名对上即可，不用改代码**：

```
Assets/StreamingAssets/PC/master/
├── boot.mp4      开机动画（当前：Windows 开机）
├── ppt.mp4       「打开PPT」内容（当前：占位图）
├── lesson.mp4    「视频播放」内容（当前：占位图）
└── shutdown.mp4  关机动画（预留，暂未接入）
```

**素材规范**：
1. 分辨率建议 1724×880（与现有素材一致）
2. **不能带黑边** —— 先跑一遍检测：
   ```bash
   ffmpeg -i 新素材.mp4 -vf "cropdetect=limit=24:round=2:reset=0" -f null -
   ```
   输出必须是 `crop=W:H:0:0`，否则先用 `crop` 裁掉
3. 有声音的素材会走 3D 音源（走近更响）

## 五、可调参数速查

在 `TwinDevicePresenter` 组件面板上：

| 参数 | 默认 | 作用 |
|---|---|---|
| `_screenStagger` | 0.15 | 逐台点亮间隔（秒），0 = 同时全亮 |
| `_projectorVignette` | 0.30 | 投影暗角强度，0 = 像 LED 屏 |
| `_projectorMaxBright` | 0.92 | 投影最高亮度，1.0 = 更亮 |
| `_projectorWarmth` | 0.12 | 灯泡色温，正暖负冷 |
| `_beamIntensity` | 2.4 | 投影聚光灯强度 |
| `_beamConeAlpha` | 0.30 | 光柱不透明度 |
| `_projectorFollowMaster` | true | 幕布是否跟随主脑开关 |
| `_screenVideoInset` | 0 | 屏幕画面内缩（0 = 铺满） |
| `_debugScreenQuad` | false | **调试**：幕布染亮红，确认改的是哪块模型 |

## 六、出问题时看哪里

```bash
LOG="C:/Users/<user>/AppData/Local/Unity/Editor/Editor.log"

# 只看最新一次编译的错误（过滤历史噪音）
n=$(grep -an "Begin MonoManager ReloadAssembly" "$LOG" | tail -1 | cut -d: -f1)
awk -v s="$n" 'NR>s' "$LOG" | grep -a "error CS" | sort -u

# 只看最新一次运行的 P26 日志
awk -v s="$n" 'NR>s' "$LOG" | grep -a "\[P26\]" | tail -30
```

### 常见症状对照

| 症状 | 看这行日志 | 病因 |
|---|---|---|
| 屏幕不亮 | `SetOn(True) → playing=? prepared=? frame=? blit=?` | `blit` 不涨 = 合成没跑；`playing=False` = 播放器没起来 |
| 幕布黑但显示器正常 | `幕布改用模型本体作载体：… （原材质槽 N 个）` | N 必须是 ≥1；若这行没出现 = `TryGetScreenFrame` 判定不像屏幕 |
| 幕布镜像 | `法线 (x, y, z)` | 法线轴决定 `right`，若镜像说明叉积符号问题 |
| 逐台点亮不生效 | `… 逐个亮=0.15s/台` | 这行没出现 = `hits.Count <= 1` 或 `_screenStagger = 0` |
| 换片没反应 | `切视频 → …` / `找不到视频「…」` | 后者会附上目录路径和现有文件列表 |
