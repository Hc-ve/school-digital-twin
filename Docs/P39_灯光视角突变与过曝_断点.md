## 5. 事故记录（已解决，防重踩）

- **MCP 桥接会话丢失**："Session not found"——play 低帧（9.7）时 execute_code 大调用压垮桥接。重连无效、重启 Unity 无效、重启 ZCode 后 unityMCP 工具从会话消失。**根因：ZCode 会话的 MCP 工具集在对话创建时固定**，服务重启/重连不注入已开对话。解法 = 新开对话（配置本身正确：http://127.0.0.1:8080/mcp 绿点）。
- 教训：①play 中 execute_code 拆最小调用；②改外部 API 前先 grep 包内源码（`Library/PackageCache/com.unity.postprocessing@3.2.2/.../ColorGrading.cs`）；③固定机位要 disable TwinThirdPersonCamera 或用 manage_camera 的 view_position/view_rotation 原子定位。
