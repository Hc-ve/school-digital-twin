## 1. 真实荧光灯 / LED 灯管「关灯态」外观

**【来源】**
- 百度百科《LED 日光灯灯罩》<https://baike.baidu.com/item/led日光灯灯罩/15732361>：「LED 日光灯灯罩…用于聚集光线并使其均匀扩散，避免刺眼现象」。
- 1688 光扩散 PC 料商品页 <https://www.1688.com/jiage/-B9E2C0A9C9A27063C1CF.html>：「PC 光扩散奶白色 LED 照明灯管外壳，扩散率 80~90%」。
- 百度智能回答《日光管刚点亮时有一层白膜》<https://agents.baidu.com/content/question/cc8672045efdbbac5f313ffe>：关灯时可见的是扩散罩 / 荧光粉层的**乳白雾面**，LED 灯管「白膜多为扩散罩/PC 罩的雾化效果」。
- **项目内实测**：`Assets/TirGames/SchoolScene/Models/Interior/Lights/Materials/LightLum01.mat`
  （mtime 与内容核对）`_EmissionColor: {r: 0, g: 0, b: 0, a: 1}`、`m_ValidKeywords` 含 `_EMISSION` / `_NORMALMAP` / `_SPECGLOSSMAP`，
  是标准 Specular 工作流 + 白/灰乳白漫反射罩。**关灯态资产本身是正确的。**

**【对本项目的指导结论】**
关灯态 = **乳白/灰白不发光罩面**，允许有轻微环境光反射，但**绝不能有自发光**。
→ 开关方案必须是「双态」：关态 emission 严格为 0（或切换回关态材质），不能靠把 emission 调到很低蒙混。
→ 现有 `LightLum01.mat` 可直接作为关态基准，**不需要新建关态材质**，更不需要改资产。

## 2. 「开灯态」外观：管壁均匀性、暗区、光色与色温

**【来源】**
- 百度百科《冷白色荧光灯》<https://baike.baidu.com/item/冷白色荧光灯/8993741>：CIE 将其归为 F2 标准荧光灯光源，「相关色温为 **4150K**，属于中性色温区间，适用于办公室、商业空间、医院」，颜色由内部磷涂层决定。
- 百度百科《荧光灯》<https://baike.baidu.com/item/荧光灯/7916488>：低压汞灯，紫外线激发荧光粉发出可见光 → **发光来自整根管壁的荧光粉层，不是两端点光源**。
- 灯具检测方法科普 <http://baijiahao.baidu.com/s?id=1881599143628772599>：「荧光灯管重点查看…**荧光粉涂层是否均匀**、两端灯丝部位有无发黑或脱粉痕迹」；LED 产品查「扩散罩**透光的均匀性**」。→ 合格灯管的验收标准是**整根均匀、无斑马纹、无暗区**。
- **项目内实测**：素材包自带 `LightLum01On.mat` → `_EmissionColor: {r: 1.5, g: 1.5, b: 1.5, a: 1}`、
  `_ValidKeywords` 含 `_EMISSION`、专用 `_EmissionMap`；`_Glossiness: 0.5`。
  同目录 `Textures/LightLum01Emmision.png` 即该发光遮罩。
- **《异环》参考图实测**（主理人提供，1810×907，本轮用 PIL 逐像素统计，见第 7 条）：
  灯管主体亮度 p10/p50/p90 = **0.423 / 0.768 / 0.998**，峰值 1.000 → 管壁整体接近饱和白、无暗段。

**【对本项目的指导结论】**
开灯态 = **整根管壁均匀接近饱和的冷白/中性白（约 4000~5000K）**，不能只亮两端、不能有条带状暗区。
→ **必须用 `_EmissionMap` 遮罩**来约束发光区域（只让管壁发光、金属端盖/支架不发光），
  单纯给整份材质刷一个 `_EmissionColor` 会把灯具外壳一起点亮，正是上一轮「糊成一块白」的成因之一。
→ 素材包 `LightLum01On.mat`（1.5 冷白 + 专用 emission map）是**现成且正确的口径**，
  但任务包禁止改 `.mat` 资产，因此应在**运行时克隆**该材质（不落盘），而不是改资产本身。
→ 目标色按 4150K 中性白取，避免上一轮 `_lampEmission = (0.60,0.56,0.46)` 那种明显偏黄。

## 3. 开灯后的「光晕 / 扩散」特征及引擎对应手段

**【来源】**
- 百度百科《Bloom（图像技术）》<https://baike.baidu.com/item/Bloom/22148711>：「模拟真实相机成像伪影，使画面中的明亮区域向外扩散形成光晕…实现通常包括**亮区域检测、高斯模糊、效果合成**」，应用于《半条命2》《原神》等。
- 《【TA100】Bloom 算法》<https://blog.csdn.net/weixin_45810196/article/details/131378036> 与《Bloom 算法详解》<https://blog.csdn.net/wrl780143706/article/details/120005289>：阈值提取高亮 → 多级高斯模糊 → 叠加回原图；扩散半径由 diffusion / mip 级数控制，强度按距离衰减。
- 《Bloom 辉光后处理笔记》<https://zhuanlan.zhihu.com/p/2005693629142934910>：「Bloom 是模拟光学现象；属于艺术增强，不完全等同于物理真实」。
- **PPv2 源码实测**（`Library/PackageCache/com.unity.postprocessing@3.2.2/PostProcessing/Runtime/Effects/Bloom.cs`）：
  `lthresh = Mathf.GammaToLinearSpace(settings.threshold.value)`；
  `intensity = RuntimeUtilities.Exp2(settings.intensity.value / 10f) - 1f`；
  判定 `IsEnabledAndSupported()` → `enabled.value && intensity.value > 0`。
- **《异环》参考图实测**：距管 10px 亮度均值 0.542 → 25px 0.488 → 45px 0.436 → 70px 0.392，
  天花板暗区 p50 仅 0.201。**光晕是柔和、连续、约 3~5 倍管宽的衰减带，不是硬边光斑。**

**【对本项目的指导结论】**
管外柔晕 = **屏幕空间 Bloom**，不是几何面片、也不是点光源（点光源照亮的是场景，不会在管体周围形成镜头光晕）。
→ 必须在 PPv2 的 Bloom 上做，且必须同时满足三个条件：`enabled.value = true`、`intensity.value > 0`、
  HDR 源亮度超过 `GammaToLinearSpace(threshold)`。
→ `diffusion` 控制扩散半径（默认 7），参考图的宽柔晕需要偏大 diffusion；
  `intensity` 是 Exp2 标度，**0.55 只等于 0.039 的实际强度**，要出可见晕必须显著更大。
→ 天花板「只有淡局部光斑」= 光晕叠加在暗天花板上，**不能把天花板整体提亮**；
  因此 Bloom 阈值不能过低（低阈值会让所有浅色墙面一起发光）。

## 6. Unity 内置管线实现手段盘点与局限

**【来源】**
- Unity 官方手册《发光材质》<https://docs.unity.cn/cn/current/Manual/lighting-emissive-materials.html>：
  「Emission 是标准着色器的属性，允许场景中的**静态对象**发光……**只有 Inspector 中标记为 Static 或 Lightmap Static 的对象才会接受发光材质的光**」。
- Unity 官方手册《Emission》<https://docs.unity.cn/cn/current/Manual/StandardShaderMaterialParameterEmission.html>：
  「向材质添加发光可使材质在场景中显示为可见光源」。
- 《Unity Standard Shader Emission 参数详解》<https://blog.csdn.net/qq_40882017/article/details/148335178>：
  GI 三档 `Realtime` / `Baked` / `None`——**`None` 时自发光仅影响自身外观，不照亮其他物体**。
- Unity 开发者社区《Post Processing 的使用》<https://developer.unity.cn/projects/5db287a9edbc2a0021f812fe>：
  「Camera 上添加 Post Process Layer…**新建一个 Layer: Post Processing，Layer 组件的 Layer 指定到该层，
  Post Process Volume 组件也要指定到该层，否则后处理（抗锯齿除外）将不起作用**」。
- **项目内 PPv2 源码实测**（包 `com.unity.postprocessing@3.2.2`）：
  - `PostProcessEffectSettings.cs:94-97` → `IsEnabledAndSupported()` **只返回 `enabled.value`**；
    `active` 是另一回事（`active` 仅表示这组参数是否参与混合）。
  - `PostProcessVolume.cs:120-139` → **`profile` getter 会克隆 `m_InternalProfile`**，
    与 `sharedProfile`（资产本体）是两个不同对象。
  - `PostProcessLayer.cs:1262-1267` → `RenderEffect<Bloom>()` 在 `ColorGrading` **之前**执行。
  - `Bloom.cs:171` → `lthresh = Mathf.GammaToLinearSpace(threshold)`；`:212` → `intensity = Exp2(v/10)-1`。

| 手段 | 能做到 | 做不到 / 局限 |
|---|---|---|
| **Standard Emission** | 让灯管**自身**发亮；配 `_EmissionMap` 可精确限定发光区域 | **不照亮周围**（`GI=None` 时纯自身；`Baked/Realtime` 需静态标记 + 烘焙，而 D13 已弃用烘焙数据）；仅靠它永远没有「往外晕开」的光晕 |
| **Point / Spot Light** | 真实照亮墙面、地面、天花板，产生光斑 | 不会产生镜头式管外光晕；数量多时性能与过曝风险高；**本任务明确归补光层，禁止新增** |
| **PPv2 Bloom** | 屏幕空间亮区提取 + 高斯模糊 → **管外柔晕**，唯一能对上参考图的手段 | 依赖相机 `PostProcessLayer` + Layer mask + Volume 混合；`enabled.value` 必须 true；阈值前于 ColorGrading；**全局生效**，阈值过低会让浅色墙面一起发光 |
| **加法光晕面片 / billboard** | 无后处理时也能有「假光晕」；可控范围 | 需为每盏灯建几何、始终朝向相机，穿帮/排序问题多；全楼 105 盏成本与维护都差；柔度不如高斯模糊 |

**【对本项目的指导结论】**
→ 正确组合 = **Emission（管体亮，配 EmissionMap） + PPv2 Bloom（管外柔晕）**，
  与任务包裁决 C-100/C-101「真实感 = HDR 自发光 + Bloom」一致。
→ **不能只调 `_lampEmission` 单值**（任务包明令禁止，也确实做不出光晕）。
→ 运行时改 Bloom 必须写 `enabled.overrideState/value`，并注意 `vol.profile` 与 `sharedProfile`
  是两份对象——这直接引出阶段 1 的诊断。

## 7.（加分）同类游戏对照 +《异环》参考图判读

**【来源】**

- **本轮 PIL/numpy 逐像素实测**（亮度 `0.299R+0.587G+0.114B`）：

| 区域 | 亮度 p10 | p50 | p90 | 峰值 |
|---|---|---|---|---|
| 灯管主体（垂直双管） | 0.423 | **0.768** | **0.998** | 1.000 |
| 天花板暗区（避开灯管） | 0.156 | **0.201** | 0.471 | — |
| 距管 10px 光晕带 | — | 0.542 | 0.726 | — |
| 距管 25px | — | 0.488 | 0.683 | — |
| 距管 45px | — | 0.436 | 0.635 | — |
| 距管 70px | — | 0.392 | 0.572 | — |

  全图 `>0.9` 高亮像素仅 **1.17%**，中亮（0.3~0.9）26.58%。

**判读结论**
1. **管壁**：接近饱和白且**整根均匀**，没有斑马纹或端部暗区；双管之间有一道细暗缝（两根独立管体）。
2. **光晕**：贴管处约为管体亮度的 ~0.7 倍，向外**平滑衰减**，70px 处仍有 0.392（约为暗顶的 2 倍），
   即扩散半径约 **3~5 倍管宽**、无明显截止边 → 对应 PPv2 `diffusion` 偏大、多级模糊。
3. **天花板**：暗区 p50 = 0.201，**只有灯管附近一片很淡的局部光斑**，绝无「整片天花板泛白」。
4. **对比度**：亮管 / 暗顶 ≈ **3.8 倍**（0.768 / 0.201）。这是「看起来在发光」的关键——
   不是把管子刷到多白，而是**周围要够暗**。

**【对本项目的指导结论】**
→ 目标量化锚点：开灯管体屏幕亮度落在 **0.75~1.0**，
  管外 3~5 倍管宽的柔晕带亮度约 **0.4~0.55**，
  天花板暗区维持 **≤0.25**。
→ 因此 Bloom 阈值必须**只让灯管过阈值**、不能让浅色天花板过阈值；
  emission 需要 HDR（>1）才能在 tonemap 前稳过阈值，但**不能把整份材质刷白**（要靠 EmissionMap 限定区域）。
→ 关灯态则回到乳白罩、不发光，与暗顶同量级。
