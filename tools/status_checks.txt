# 验收判据清单（看板自检的数据源）

> 本文件是 `Tools/status.py` 的输入，**不是给人读的规范**。
> 每个任务包派出去时，负责人在这里加几条**可机器验证**的判据；
> 看板自动跑一遍，告诉你「这条活到底做完没有」。
>
> 为什么不写"任务 A 完成了 80%"：
> 那种百分比只能人填，人填的一定滞后、一定美化。
> 而 `grep -c "_nTypeCount"` 是 0 还是 6，改不了。
>
> 格式（三字段，`|` 分隔，`#` 开头是注释）：
>   ID | 人类可读的判据 | 检查命令与期望
>
> 检查命令用下面四种前缀之一：
>   `grep:N:文件:模式`   —— 文件中匹配**行数**应等于 N
>   `grep+:N:文件:模式`  —— 文件中匹配行数**至少** N（用在一处声明多处使用的字段）
>   `grep0:文件:模式`    —— 文件中**不得出现**该模式（期望 0）
>   `has:文件`           —— 文件存在
>   `hasnot:文件`        —— 文件不存在
>
> 文件路径相对仓库根。模式按**正则**处理（注意 Windows 下用 / 分隔）。
